# **JARVIS**
**Version: 2.3.0**: Added sched command's learning type variable

<br>

**JARVIS** is a Discord bot for me and my friends to use to get our schedule for our online classes. The name **JARVIS** is an acronym for **"Just A Really Very Intelligent System."** His name is inspired by a fictional character in the Marvel Cinematic Universe film franchise, namely the household butler of the Stark family and another AI designed by Stark.

This Discord bot tracks me and my friends' class schedules, online *(synchronous),* offline *(asynchronous),* and face-to-face.

---

## **Requirements:**
- Python 3.x
- discord.py
- flask
### **(1) Register your bot on discord**
- See the [discord.py documentation](https://discordpy.readthedocs.io/en/stable/discord.html) on how to create an application and a bot.
- Make sure both `bot` and `application.commands` scopes are selected.
- Put your **bot token,** **discord id,** and **your class schedule** on your secrets *(if you use replit)* or an `.env` file

---

## **How to Use:**
- Follow the requirements written above.
- Run _src/main.py_.
